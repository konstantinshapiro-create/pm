# Code Review — Full Codebase (frontend/)

Scope: comprehensive review of the entire current codebase (no diff/PR target —
`frontend/` is the only implemented part of the project per `CLAUDE.md`).
Effort: high. Methodology: 8 finder angles (line-by-line scan, removed-behavior
audit, cross-file trace, reuse, simplification, efficiency, altitude,
CLAUDE.md conventions) followed by recall-biased verification.

Files read in full: `src/lib/kanban.ts`, `src/lib/kanban.test.ts`,
`src/components/KanbanBoard.tsx`, `KanbanBoard.test.tsx`, `KanbanCard.tsx`,
`KanbanCardPreview.tsx`, `KanbanColumn.tsx`, `NewCardForm.tsx`,
`src/app/page.tsx`, `src/app/layout.tsx`, `src/app/globals.css`,
`tests/kanban.spec.ts`, config files (`vitest.config.ts`,
`playwright.config.ts`, `tsconfig.json`, `next.config.ts`, `eslint.config.mjs`),
`package.json`, `.gitignore`, plus repo-root `AGENTS.md`, `CLAUDE.md`,
`docs/PLAN.md`.

The codebase is small and no correctness "crash" bugs were found in the core
`moveCard` drag-and-drop logic — it was checked against dnd-kit's own
`arrayMove` semantics and matches for every branch (same-column reorder,
cross-column move, drop-on-column vs drop-on-card). The findings below are the
issues that survived verification, ranked most severe first.
